# 花园物语 (Garden Story)

一个温馨治愈的交互式花园种植游戏，使用 Phaser.js 开发，带你体验从播种到收获的完整园艺乐趣！

## 🌸 游戏特色

### 核心玩法
- 🌱 **种植系统** - 播种、浇水、施肥，培育各种美丽花卉
- 🐶 **宠物互动** - 与可爱小狗建立深厚友谊，解锁每日奖励
- 💰 **经济系统** - 通过出售花卉和产品赚取金币
- 🏡 **花园装饰** - 布置各种家具和装饰，打造专属花园
- 🛠️ **工坊系统** - 制作高级道具和肥料，提升种植效率
- 💣 **扫雷小游戏** - 点击灌木丛进入，成功避开所有菊花获得种子奖励

### 特色功能
- 🎁 **满级礼包** - 小狗好感度满级后，每日可领取5袋种子
- 🔄 **循环生态** - 杂草制作肥料，肥料培育花卉，形成生态循环
- 🎨 **精美界面** - 清新可爱的视觉风格，流畅的动画效果
- 💾 **数据持久化** - 自动保存游戏进度，随时继续冒险
- 📖 **新手教程** - 首次进入游戏提供图文教程，快速上手
- 🔊 **音效系统** - 杂草生长和移除都有音效反馈

## 🎮 快速开始

### 环境要求
- Node.js 16+ 
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```
开发服务器将在 `http://localhost:5173` 启动。

### 构建项目
```bash
npm run build
```
构建完成后，文件将输出到 `dist_build/` 目录。

### 预览构建结果
```bash
npm run preview
```
或者直接使用 http-server：
```bash
http-server dist_build -p 8080
```

## 📖 游戏指南

### 基础操作
1. **开始游戏** - 打开 index.html，点击告示牌开始你的花园之旅
2. **新手教程** - 首次进入游戏会显示图文教程，可随时重玩
3. **种植花卉** - 在工坊制作或购买种子，播种后等待生长
4. **照料植物** - 及时浇水、施肥，确保植物健康成长
5. **收获出售** - 收获成熟花卉，出售赚取金币
6. **装饰花园** - 购买各种家具，打造美丽花园
7. **互动小狗** - 赠送花朵提升好感度，解锁每日礼包
8. **扫雷小游戏** - 点击花园中的灌木丛进入，成功避开所有菊花获得种子奖励

### 主要角色
- 🐶 **旺财** - 你的忠实伙伴，开局即拥有，满级后可领取每日礼包
- 👨🌾 **园丁** - 就是你！通过辛勤劳作打造梦幻花园

### 道具系统
- 🌾 **镰刀** - 快速清理杂草
- 🪓 **割草机** - 大面积清理杂草
- 🧪 **肥料** - 加速植物生长，可兑换狗粮
- 🎁 **狗粮** - 快速提升小狗好感度
- 🌰 **种子** - 种植各种花卉

### 好感度系统
| 物品 | 增加好感度 |
|------|-----------|
| 蝴蝶兰 | +1 |
| 菊花 | +2 |
| 星月相随 | +5 |
| 过路黄 | +5 |
| 美味狗粮 | +30 |

## 🎯 游戏目标

1. **新手阶段** - 完成新手教程，熟悉种植操作，赚取第一桶金
2. **发展阶段** - 扩建花园，购买高级道具
3. **成熟阶段** - 培养小狗满级，解锁每日礼包
4. **终极目标** - 打造完美花园，收集所有花卉和家具

## 🎮 小游戏说明

### 扫雷小游戏
- **入口** - 在 game.html 中点击灌木丛进入
- **玩法** - 标准扫雷游戏，点击翻开格子，右键标记
- **主题** - 地雷替换为菊花，格子有玻璃装饰
- **奖励** - 第一次胜利可获得1包种子
- **规则** - 开始前会显示游戏规则介绍

## 🔧 开发说明

### 技术栈
- **Phaser.js** - 游戏引擎
- **Vite** - 构建工具
- **JavaScript** - 游戏逻辑
- **HTML/CSS** - 界面设计

### 自定义开发
- 添加新植物：在 `public/js/plants/` 目录下创建新植物逻辑
- 添加新家具：在 `public/js/furniture/` 目录下创建新家具组件
- 修改游戏数据：在 `public/js/core/gameData.js` 中调整游戏参数
