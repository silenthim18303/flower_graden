# 花园小游戏

一个基于 Phaser 4.1.0 开发的休闲花园经营小游戏。

## 游戏简介

在这个花园小游戏中，你可以：
- 收集杂草，通过堆肥转化为肥料
- 种植各种花卉（蝴蝶兰、菊花、星月相随、过路黄）
- 兑换道具（镰刀、割草机、随机种子）
- 摇晃芒果树获取肥料
- 收集花卉到花箱中
- 使用电脑进入电商页面出售花卉赚取金币
- 用金币购买肥料和家具

## 游戏系统

### 资源系统
- **杂草**：自动生长，点击收集，上限30个
- **肥料**：通过堆肥（30杂草=1肥料）或摇树获得
- **种子**：在商店用5肥料兑换
- **货币**：通过出售花卉获得，用于购买肥料和家具

### 花卉系统
| 花卉 | 获取方式 | 概率 | 出售价 |
|------|----------|------|--------|
| 蝴蝶兰 | 自然生长 | 30% | 1金币 |
| 菊花 | 施肥生长 | 30% | 5金币 |
| 星月相随 | 使用种子 | 20% | 10金币 |
| 过路黄 | 使用种子 | 15% | - |

### 道具系统
| 道具 | 价格 | 功能 |
|------|------|------|
| 镰刀 | 10肥料 | 一键收割所有杂草 |
| 割草机 | 20肥料 | 自动除草（屏幕杂草满30时，1秒后自动收割全部） |
| 随机种子 | 5肥料 | 随机长出星月相随或过路黄 |

### 电商系统
| 商品 | 价格 | 说明 |
|------|------|------|
| 肥料 | 3金币 | 购买1包肥料 |
| 桌椅套装 | 50金币 | 购买后在花园中显示 |
| 精致鸟笼 | 50金币 | 购买后在花园中显示 |

### 芒果树
- 点击芒果树跳转到摇一摇页面
- 50%概率获得肥料
- 冷却时间：5分钟

### 家具系统
- 在电商页面用金币购买家具
- 购买后自动在花园页面显示
- 数据通过布尔值同步到 GameData
- 当前家具：桌椅套装、精致鸟笼

## 左上角常驻显示
所有页面左上角常驻显示：
- 杂草数量
- 肥料数量
- 种子数量
- 货币数量

## 数据存储

游戏使用 localStorage 存储数据，包括：
- 杂草数量
- 肥料数量
- 种子数量
- 货币数量
- 镰刀解锁状态
- 割草机解锁状态
- 桌椅解锁状态
- 鸟笼解锁状态
- 花卉收集记录
- 摇树冷却时间

## 操作说明

1. **收集杂草**：点击屏幕上的杂草
2. **施肥**：点击工具栏的施肥按钮
3. **使用种子**：点击工具栏的种子按钮
4. **收割杂草**：点击工具栏的镰刀按钮
5. **自动除草**：点击工具栏的割草机按钮开启/关闭
6. **摇树**：点击芒果树，跳转到摇一摇页面
7. **堆肥**：在工坊页面点击堆肥桶，跳转到堆肥页面
8. **查看花箱**：在工坊页面点击花箱，跳转到花箱页面
9. **使用电脑**：在工坊页面点击电脑进入电商页面
10. **购买家具**：在电商页面或花园页面的订购家具按钮

## 交互设计

所有游戏内图层点击后跳转到独立的 HTML 页面，避免了弹窗与 Phaser Canvas 之间的点击穿透问题。每个页面都包含：
- 左上角状态栏（杂草、肥料、种子、货币数量）
- 返回按钮导航
- 完整的功能逻辑

## 技术栈

- **游戏引擎**：Phaser 4.1.0
- **数据存储**：localStorage
- **前端**：HTML5 / CSS3 / JavaScript

## 浏览器兼容性

支持所有现代浏览器，推荐使用 Chrome 或 Firefox。

## 开发说明

- 所有游戏数据通过 `gameData.js` 统一管理
- 每个游戏系统独立一个 JS 文件
- 交互功能使用独立 HTML 页面实现，避免点击穿透
- 工具栏自适应小屏手机（使用 vw 单位）
- 家具系统通过 GameData 布尔值控制显示
